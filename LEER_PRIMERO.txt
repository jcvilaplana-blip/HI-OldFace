OldFace — LEER PRIMERO
======================

Toda la documentación actual (estructura, arquitectura, variables de entorno, despliegue y APK)
está en README.md.

Resumen:
  - Producción: https://oldface.app
  - Llamadas, directos y karaoke: servidor RTC propio (rtc-server/), sin servicios de terceros.
  - Desplegar: python deploy-vps.py (desde la carpeta superior, fuera del repo).
  - APK: cd frontend → npm run build → npx cap sync android → npx cap open android.

Las contraseñas y secretos van SOLO en los archivos .env del servidor (nunca en el repositorio).
