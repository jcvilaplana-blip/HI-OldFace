Abre PowerShell y navega a la carpeta frontend:
(ajusta la ruta a donde hayas descomprimido el ZIP)

  cd "RUTA_DONDE_DESCOMPRIMISTE\oldface-app\frontend"

Verifica que estás en el lugar correcto:
  dir package.json
  (debe mostrar el archivo)

Luego ejecuta en orden:
  npm install
  npm install @zegocloud/zego-uikit-prebuilt zego-express-engine-webrtc
  npm run build

Al terminar aparecerá la carpeta "dist\" dentro de frontend\

En "Additional nginx directives" pegar:

  location / {
      try_files $uri $uri/ /index.html;
  }
  location /api/ {
      proxy_pass http://127.0.0.1:3001/;
      proxy_http_version 1.1;
      proxy_set_header Host $host;
      proxy_set_header X-Real-IP $remote_addr;
      proxy_set_header X-Forwarded-Proto $scheme;
  }
  location ~* \.(js|css|png|jpg|svg|woff2?)$ {
      expires 1y;
      add_header Cache-Control "public, immutable";
  }
